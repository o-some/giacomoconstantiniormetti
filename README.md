# Iormetti Concepts

Kunde: **Giacomo Constantin Iormetti**. Repository: `o-some/giacomoconstantiniormetti`.

Eigenständige statische Website für Fitness und Coaching, entwickelt anhand der aktuell gelesenen CAF 1.21.0 / MasterBrain 4.6.1 Vorgaben. Designreferenz: **044 · Fitness – Built Different**. Es wurden Gestaltungsprinzipien übersetzt, keine Quellbilder, Texte oder Marken der Vorlage übernommen.

## Öffnen

`site/index.html` im Browser öffnen. Alle Ressourcen sind lokal enthalten. Alternativ im Projektordner `python3 -m http.server 8765 --directory site` ausführen. Keine Installation und kein Build erforderlich.

## Implementiert

- Responsive Startseite mit sechs redaktionellen Abschnitten, Angeboten, Prozess, Person, FAQ und Einstieg.
- Sechs eigenständige KI-generierte Bildmotive sowie angepasster Logoentwurf.
- Mobile Navigation mit Escape, Fokusführung und Schließen bei Navigation.
- Scroll-Reveals mit Reduced-Motion- und No-Script-Verhalten.
- Lokale Gesprächsnotiz mit Pflichtfeldern und TXT-Download; keine Datenübermittlung.
- Lokale Schriftdatei mit OFL-Lizenz, Metadaten, Favicon, noindex.
